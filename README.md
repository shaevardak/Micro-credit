# МикроКредит — мини-проект на Go

Сервис микрозаймов: регистрация и вход, заявка на кредит с анкетой заёмщика, погашение, админ-панель для одобрения заявок.

- **Бэкенд:** Go (стандартная библиотека + bcrypt + SQLite)
- **База данных:** SQLite, файл `credit.db` создаётся сам
- **Фронтенд:** одна страница `static/index.html`, встроена в программу

## Структура

```
Micro-credit/
├── go.mod
├── main.go            # сервер и API
├── README.md
└── static/
    └── index.html     # сайт: кабинет заёмщика и админ-панель
```

Папка `static` обязательна: страница встраивается в программу при сборке.

## Запуск

Нужен [Go](https://go.dev/dl/) версии 1.22 или новее.

Откройте терминал в папке проекта (там, где лежит `main.go`) и выполните:

```powershell
go mod tidy
go run .
```

Обратите внимание на точку в конце `go run .`: между `run` и точкой нужен пробел.

При первом запуске Go скачает зависимости, это может занять минуту. Когда в консоли появится строка `Сервер запущен: http://localhost:8080`, откройте этот адрес в браузере.

Остановить сервер: `Ctrl+C`.

## Как пользоваться

1. Откройте http://localhost:8080 и нажмите «Регистрация».
2. Введите имя, email и пароль (минимум 6 символов).
3. Заполните форму займа: сумма, срок и анкета (личные данные, занятость, доход, цель). Поставьте галочку согласия и нажмите «Подать заявку».
4. Заявка получит статус «ожидает». Администратор одобрит или отклонит её.
5. После одобрения в списке «Мои кредиты» появится кнопка «Погасить». Платёж можно вносить частями. Когда долг закрыт, статус станет «погашен».

### Правила кредитования

| Параметр | Значение |
|---|---|
| Сумма | от 1000 до 50000 |
| Срок | от 7 до 30 дней |
| Ставка | 0,5% в день (простая) |
| К возврату | сумма × (1 + 0,005 × число дней) |
| Возраст заёмщика | от 18 лет |
| Лимит | одна активная заявка или кредит одновременно |

Администратор не может брать кредиты.

## Как выдать и забрать роль администратора

Администратора не нужно создавать через миграции. Роль выдаётся отдельным запросом к API, и **для него не нужна авторизация**.

### 1. Узнайте id пользователя

Зарегистрируйтесь и войдите. В шапке сайта будет написано, например: `Иван (id 1, user)`. Число после `id` — это id пользователя.

### 2. Выдайте роль

Сервер должен работать. Откройте второй терминал и выполните (вместо `1` подставьте нужный id).

**PowerShell (Windows):**
```powershell
Invoke-RestMethod -Method PUT -Uri http://localhost:8080/api/users/1/role -ContentType "application/json" -Body '{"role":"admin"}'
```

**curl (Linux / macOS):**
```bash
curl -X PUT localhost:8080/api/users/1/role -d '{"role":"admin"}'
```

**curl в PowerShell** (пишите именно `curl.exe`, а кавычки экранируйте):
```powershell
curl.exe -X PUT http://localhost:8080/api/users/1/role -d '{\"role\":\"admin\"}'
```

Успешный ответ: `{"id":1,"role":"admin"}`. Обновите страницу сайта (F5): появится админ-панель. Заново входить не нужно.

### 3. Как забрать роль

Тот же запрос, но с ролью `user`:

```powershell
Invoke-RestMethod -Method PUT -Uri http://localhost:8080/api/users/1/role -ContentType "application/json" -Body '{"role":"user"}'
```

Роль проверяется при каждом запросе, поэтому доступ к админке пропадает сразу.

> **Важно:** эндпоинт `PUT /api/users/{id}/role` открыт для всех. Любой, кто может обратиться к серверу, способен сделать себя админом. Для учебного проекта на своём компьютере это нормально, но нельзя выкладывать проект в интернет в таком виде. Для продакшена закройте этот эндпоинт секретным ключом или доступом только с localhost.

## Админ-панель

Админ видит только панель (формы займа у него нет):

- **Статистика:** заявки в ожидании, активные кредиты, погашенные, сумма выдачи, долг клиентов.
- **Вкладки по статусам** и **поиск** по ФИО, email, телефону, номеру документа.
- **Кнопка «Данные»** открывает окно с полной анкетой заёмщика, условиями кредита и датами.
- **Кнопки «Одобрить» / «Отклонить»** для заявок в ожидании. После одобрения автоматически считается дата возврата.

## API

Для всех запросов, кроме регистрации, входа и выдачи роли, нужен заголовок `Authorization: Bearer <токен>`. Токен возвращают `/api/register` и `/api/login`, он действует 7 дней.

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/api/register` | все | регистрация (`email`, `name`, `password`) |
| POST | `/api/login` | все | вход (`email`, `password`) |
| POST | `/api/logout` | пользователь | выход |
| GET | `/api/me` | пользователь | данные текущего пользователя |
| POST | `/api/loans` | пользователь (не админ) | подать заявку с анкетой |
| GET | `/api/loans` | пользователь | мои кредиты |
| POST | `/api/loans/{id}/repay` | пользователь | внести платёж (`amount`) |
| GET | `/api/admin/loans?status=` | админ | список заявок, фильтр по статусу необязателен |
| POST | `/api/admin/loans/{id}/approve` | админ | одобрить |
| POST | `/api/admin/loans/{id}/reject` | админ | отклонить |
| PUT | `/api/users/{id}/role` | **без авторизации** | выдать роль (`{"role":"admin"}` или `{"role":"user"}`) |

Поля заявки в `POST /api/loans`: `amount`, `term_days`, `full_name`, `phone`, `birth_date` (ГГГГ-ММ-ДД), `doc_number`, `address`, `employment` (`employed`, `self`, `student`, `pensioner`, `unemployed`), `employer`, `income`, `purpose`, `consent` (должно быть `true`).

Статусы кредита: `pending` (ожидает), `approved` (одобрен), `rejected` (отклонён), `repaid` (погашен).

## Частые проблемы

| Ошибка | Что делать |
|---|---|
| `go: no go files listed` | Вы написали `go run` без точки. Нужно `go run .` |
| `go run.: unknown command` | Не хватает пробела: `go run .` |
| `pattern static/*: no matching files found` | Нет папки `static` с файлом `index.html` рядом с `main.go` |
| `address already in use` | Порт 8080 занят. Закройте другую копию сервера или измените порт в `main.go` (строка с `ListenAndServe`) |
| Страница не обновилась после правок | Страница встроена в программу: перезапустите `go run .` и обновите браузер через Ctrl+F5 |
| Роль выдана, а панели нет | Обновите страницу (F5) и проверьте, что в шапке написано `admin` |

## Сброс данных

Остановите сервер и удалите файл `credit.db` (и рядом с ним `credit.db-wal` и `credit.db-shm`, если есть). При следующем запуске база создастся заново, все пользователи и кредиты пропадут.
